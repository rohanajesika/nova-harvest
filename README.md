Nova Harvest is an original arcade survival game: guide a lantern-moth through a
gloomy nebula, gather falling star-seeds to build a combo, blast the wisps that
chase you, and banish the Gloomheart boss to clear all 8 waves. Built with plain
HTML, CSS and JavaScript on canvas — no libraries, no network requests, all sound
synthesised live with WebAudio.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Move with WASD or the arrow
keys, aim with the mouse, hold click or Space to shoot, P pauses, M mutes, R
restarts.
